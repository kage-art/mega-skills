## 📂 Detailed Skill Breakdown by Domain

### 1. Mobile Development (Android & iOS)
- **`android-master`**: Complete modern Android engineering (Jetpack Compose, Kotlin, StateFlow, Room, Hilt).
- **`jetpack-compose-performance`**: Recomposition optimization, stability markers, lazy list keys.
- **`android-edge-to-edge`**: Complete WindowInsets handling (status bar, navigation bar, keyboard IME).
- **`android-navigation-3`**: Type-safe navigation and predictive back gestures.
- **`android-anr-audit`**: Diagnosing main thread blockage, StrictMode, background coroutines.
- **`ios-swiftui-master`**: Swift 6 concurrency (`@MainActor`, `async/await`), SwiftUI `@Observable`, NavigationStack.
- **`ios-apple-design-master`**: 123 pages of official Apple HIG guidelines, SF Symbols 6, Liquid Glass, safe areas.
- **`react-native-best-practices`**: Software Mansion architecture, Expo Router, TypeScript strictness.
- **`react-native-reanimated`**: Native thread 60fps animations with Reanimated 4.
- **`react-native-pulsar-haptics`**: Cross-platform sensory haptic feedback.
- **`flutter-master-craft`**: Adaptive UI, Riverpod state management, 120fps widget rendering.
- **`mobile-anti-slop`**: Eradicates keyboard obscuring inputs, clipped text under font scaling, and tiny touch targets.

### 2. Anti-Slop & Design Craft
- **`antislop-code`**: Removes fake placeholders, dead code, unhandled errors, and comment clutter.
- **`antislop-ui`**: Eradicates generic purple gradients, bubbly rounded cards, and washed-out grey text.
- **`antislop-copywriting`**: Replaces buzzwords with crisp, punchy, human technical copy.
- **`impeccable-craft`**: Enforces strict spatial rhythm, typographic hierarchy, and visual balance.
- **`hallmark-themes`**: 48 authentic, production-ready themes (Newsprint, Solstice, Terminal, Riso, Werkstatt).
- **`baseline-ui`**: Design engineering component tokens and layout foundations.
- **`fixing-accessibility`**: WCAG AA/AAA compliance, ARIA attributes, keyboard navigation, focus indicators.

### 3. Senior Engineering, TDD & Verification
- **`superpowers-test-driven-development`**: Red-Green-Refactor loop; write failing tests first.
- **`superpowers-systematic-debugging`**: Root cause analysis and minimal reproduction scripts before code edits.
- **`superpowers-verification-before-completion`**: Verifies work with tests, builds, and screenshots before declaring done.
- **`reticle-agentic-tdd` & `reticle-audit-my-app`**: Automated headless browser testing of user flows.
- **`reticle-replay-user-flows`**: Replays captured user interactions to verify regressions.
- **`ponytail-review` & `ponytail-debt`**: Pragmatic senior developer review, ROI analysis, and tech debt reduction.

### 4. Security & Safety Auditing
- **`strix-penetration-testing-with-strix`**: Automated penetration testing of web applications, APIs, and networks.
- **`strix-owasp-top-10-testing`**: Audits codebases against SQLi, XSS, CSRF, broken access control, and insecure configs.
- **`skillspector-safety-scanner`**: Scans agent skills and tools for prompt injection, overprivileged permissions, and malicious commands.

### 5. Creative Motion, 3D & WebGL
- **`gsap-motion-master`**: Master GSAP 3 timelines, ScrollTrigger pinning/scrubbing, and `matchMedia` responsive motion.
- **`lenis-smooth-scroll`**: Momentum smooth scrolling synchronized with GSAP tickers and reduced-motion checks.
- **`vanta-3d-backgrounds`**: Animated 3D WebGL backgrounds (Waves, Net, Halo, Dots, Fog) with Three.js.
- **`fixing-motion-performance`**: Ensures animations use GPU-accelerated `transform` and `opacity` properties without layout thrashing.
