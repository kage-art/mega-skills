To fix this, I aggregated and curated 55+ specialized agent skills from top open-source communities (Google Android, Anthropic, Apple design, Software Mansion, and security researchers) into a single unified master suite with a single-command installer:

  npx kage-art/mega-skills

What it includes:
- Anti-Slop Directive: Enforces human typography, WCAG AA/AAA contrast, and production implementations.
- Native Android: Edge-to-edge window insets, Jetpack Compose 48dp touch targets, ANR stack audits, and CameraX.
- Native iOS: Swift 6 Concurrency (@MainActor), SwiftUI Apple HIG, SF Symbols 6, and Liquid Glass.
- Cross-Platform: Software Mansion React Native (Reanimated, Worklets) and Flutter craft.
- Cyber Security Scanners: Built-in deterministic scanners that audit downloaded agent skills for prompt injection, reverse shells, and malicious package hooks (preinstall/postinstall) before setup.

Everything installs locally into your agent config directories (~/.gemini/config, ~/.claude, and workspace .cursorrules).

Code is Apache 2.0: https://github.com/kage-art/mega-skills

I'd love your feedback on additional skills or mobile edge cases we should cover!
