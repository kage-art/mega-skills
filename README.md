## 🌟 Why MegaSkills?

Most AI coding assistants suffer from **AI Slop**:
- Tacky, repetitive purple/cyan gradients and generic floaty bubble cards.
- Lazy mockups with `// TODO: Implement later` and unhandled edge cases.
- Mobile screens with virtual keyboards obscuring text inputs, clipped labels under accessibility font scaling, and broken back navigation.
- Sloppy shotgun debugging and hallucinated solutions with no automated verification.

**MegaSkills unites the best agent skills repositories into a single cohesive, standardized, and vetted master library:**

```
MegaSkills/
├── anti-slop/             # Purges AI slop in code, UI, copywriting, and design craft
├── mobile-android/        # Google Jetpack Compose, M3, Insets, ANR prevention, Navigation 3
├── mobile-ios/            # Apple HIG, SwiftUI, Swift 6 Concurrency, SF Symbols, Liquid Glass

└── workflow-ecosystem/    # Anthropic MCP builder, skill creator, web artifacts builder
```

## 🚀 Single-Command Installation

To install the **Mega Master Skill Suite** across your entire system into all detected AI tools (**Google Antigravity**, **Claude Code**, **Cursor**, **Windsurf**, and **OpenAI Codex**):

### Method 1: NPX One-Shot (Run Anywhere, No Cloning Required)
```bash
# Downloads and installs the full Mega Master Skill suite + universal rules
npx kage-art/mega-skills
```
*(You can also run `npx kage-art/mega-skills install`, `npx kage-art/mega-skills list`, or `npx kage-art/mega-skills verify`)*

### Method 2: Web 1-Liner (Zero-Dependency)
**Windows (PowerShell):**
```powershell
irm https://raw.githubusercontent.com/kage-art/mega-skills/main/install.ps1 | iex
```

**macOS & Linux (Bash):**
```bash
curl -fsSL https://raw.githubusercontent.com/kage-art/mega-skills/main/install.sh | bash
```

### Method 3: Local Repository Execution
If you have cloned or navigated into this repository:
```bash
npx install                # Installs the complete suite directly
npm run install:master     # Installs the Mega Master Skill
npm run install:all        # Installs all 53 curated skills
```

### Method 4: Official `npx skills` Command (skills.sh Standard)
```bash
npx skills add kage-art/mega-skills -g -y
```

### Need Individual Category Profiles Instead?

* `npx kage-art/mega-skills install --profile mobile` : Installs Android, iOS, and Mobile Anti-Slop skills.
* `npx kage-art/mega-skills install --profile anti-slop` : Installs pure anti-slop code, UI, and copywriting skills.
* `npx kage-art/mega-skills install --profile engineering` : Installs TDD, systematic debugging, code review & QA.
* `npx kage-art/mega-skills install --profile creative` : Installs GSAP, Lenis, Vanta 3D, and motion.
* `npx kage-art/mega-skills install --profile security` : Installs Strix OWASP pentesting and safety scanners.

## 🔐 Cyber Security, Malware Auditing & Supply Chain Safety

MegaSkills includes a built-in **Cyber Security Suite** that protects your system before any code or skill is installed:

### Pre-Installation Cyber Threat Verification
Whenever you run `npx kage-art/mega-skills` or `npx install`, the installer **automatically runs a full static cyber audit before touching your system**:
- **0 Malware Signatures:** Scans all skills for destructive filesystem commands, reverse shells, download cradles, and obfuscated code.
- **0 Backdoors or Exfiltration:** Validates network endpoints, webhook beacons, and credential access.
- **0 Malicious Install Hooks:** Audits package manifests for dangerous `preinstall` or `postinstall` shell hooks.

### Dedicated Security Skills Included
- **`skill-malware-scanner`**: Deterministic & heuristic cyber antivirus that scans downloaded skills, prompts, and MCP servers for malicious payloads, reverse shells, and prompt injections.
- **`supply-chain-security-scanner`**: Audits packages, libraries, dependencies, and lockfiles (`package.json`, `package-lock.json`, `requirements.txt`) for CVE vulnerabilities, typosquatting attacks, and malicious install scripts before `npm install` or `pip install`.
- **`strix-owasp-top-10-testing`**: Automated penetration testing and vulnerability auditing across web applications and APIs.
- **`skillspector-safety-scanner`**: NVIDIA SkillSpector static analysis and semantic review for agent permission boundaries.

### Run Standalone Scans Anytime
```bash
# Scan any downloaded skill folder for malware & viruses
npx kage-art/mega-skills scan "/path/to/skill"

# Audit a project's packages & dependencies before install
npx kage-art/mega-skills scan-deps "/path/to/project"
```
